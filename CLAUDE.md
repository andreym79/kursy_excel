# CLAUDE.md — контекст для Claude Code

## Что это
Лендинг (HTML/CSS/vanilla JS) + немного PHP: приём заявок и подстановка текстов из Mini CRM. Без сборщиков и фреймворков — так задумано: владелец не технический специалист, хостинг обычный shared с PHP (Beget).

## Бизнес-контекст
- Продукт: очные курсы Excel в Москве, группы до 10 человек, 3 модуля (16 ч, 16 ч, 36 ч), удостоверение гос. образца.
- Преподаватель: Светлана Владимировна Кондратова, к.э.н., 20+ лет в финансах.
- **На сайте не упоминать РТУ МИРЭА и РАНХиГС** (решение владельца 02.11.2026): ни в текстах, ни в метатегах, ни в подписях к фото.
- Аудитория: руководители среднего звена, владельцы бизнеса, специалисты 25–45 лет, работающие с данными.
- Цель страницы: заявка (имя + телефон). Оплаты на сайте нет — преподаватель перезванивает.
- Трафик: Яндекс Директ. Этап — проверка спроса 1–2 месяца.

## Архитектура
- `a/index.html`, `c/index.html` — **одинаковая разметка**, различаются только содержимым hero (A — фото преподавателя в круге, C — фото занятия + карточка преподавателя), логотипом, классами секции «Программа» и подключаемой темой. Любое изменение контента/разметки вносить в ОБА варианта. Вариант G удалён 22.10.2026 (A/B-тест A против C), он есть в истории git.
- **Тексты из CRM** (модуль Mini CRM «Тексты сайта», репозиторий andreym79/minicrm): `a/index.php` и `c/index.php` отдают свой `index.html` через `api/cms.php`, который подставляет значения в элементы `data-cms="ключ"` (текст), `data-cms-href="ключ"` (адрес ссылки), `data-cms-tel` (tel: из того же поля), `data-cms-multiline`. `data-cms-label` — название поля в CRM. Элемент с `data-cms` — листовой (внутри только текст). Значения кэшируются в `storage/cms-cache.json` на `crm.cache_seconds`; CRM недоступна → последний кэш → текст из HTML. Список полей для CRM — `api/cms-fields.php` (снаружи `/cms-fields.json`, правило в `.htaccess`), собирается из разметки; новое поле = разметка в обоих вариантах + «Обновить список полей» в CRM. Ключи одинаковые во всех вариантах.
- Срок перезвона после отправки формы `main.js` берёт из `[data-cms="callback_time"]` (или `LANDING_CONFIG.callbackText`, если задан).
- Цвета/шрифты/радиусы — только через CSS-переменные в `theme-*.css`. В `base.css` не хардкодить цвета.
- Стиль (02.11.2026, «строже и современнее»): заголовки тем же Golos Text, что и текст (шрифтов с засечками нет), скругления сдержанные и одинаковые в обеих темах (6/10/14/18 px, кнопки и поля 10, плашки/метки/номера шагов 8), подписи разделов — прописные с разрядкой. Фото преподавателя (`teacher.*`) уже вырезано кругом с белыми углами — показывать только кругом.
- Переменные доступности (есть в каждой теме, при смене палитры пересчитать контраст):
  `--accent-on-dark` — акцент для текста/иконок на тёмных блоках (≥ 4.5:1 к `--brand`);
  `--focus` / `--focus-on-dark` — рамка фокуса на светлом / тёмном фоне (≥ 3:1), переключается через `--focus-ring` у тёмных контейнеров в `base.css`;
  `--input-border` — рамка полей формы (≥ 3:1 к белому); `--stars` — звёзды отзывов (≥ 4.5:1);
  `--check-icon` — галочка в списках (тёмная, если кнопка светлая — золото/янтарь); `--fact-size-mobile` — размер цифр hero на телефоне.
- CSS и JS подключены с `?v=N` (кэш в браузере на 30 дней, см. `.htaccess`). **После правки CSS/JS увеличить N во всех `index.html`.**
- Фото — WebP через `<picture>` с JPG-запасом (`teacher.webp` / `teacher.jpg`, аватарка `teacher-avatar.*` 144 px; галерея `class-lesson` / `class-room` / `class-screen`; hero C — `hero-c-lesson`). Исходники вертикальные, в файлах уже нужный кадр. `picture` в CSS — `display: contents`, а `picture > source` — `display: none`: без второго правила пустой `<source>` занимает ячейку сетки и ломает галерею.
- Видео-кружок (`.clip` в `base.css`, раздел 4 в `main.js`) под фото преподавателя: `assets/video/vpr-explain.mp4` (H.264, 400×400, круг зашит в само видео), обложка `vpr-explain-poster.webp`, субтитры `vpr-explain.ru.vtt` показываются в подписи под кругом. Видео грузится только по нажатию (`preload="none"`). Без JS работает как обычное видео с кнопками браузера. Новое видео: сжать `ffmpeg -map_metadata -1 -c:v libx264 -crf 26 -movflags +faststart -c:a aac -b:a 64k`, субтитры — Whisper `medium` (есть на компьютере владельца).
- `main.js`: не использовать `form.name`/`form.phone` (конфликт со свойствами HTMLFormElement) — только `form.elements['...']`.
- Форма шлёт JSON на `../api/lead.php`. Ответ: `{ok:true}` или `{ok:false,error}`. Каналы: Mini CRM (`/api/public/forms/<form_key>` → контакт + сделка + задача; лимит CRM 5 заявок в минуту с одного IP — все заявки идут с IP хостинга), Telegram, MAX, e-mail, копия в `storage/leads.log`.
- Кнопки с `data-cta` шлют цель `cta_click`; `data-module="…"` подставляет модуль в `<select name="module">` (значение должно ТОЧНО совпадать с `<option value>`); `data-payer="company"` выбирает радиокнопку.

## Цели Метрики (идентификаторы JS-событий)
`lead` (успешная отправка — главная цель для Директа), `lead_error`, `cta_click`, `program_open`, `phone_click`, `messenger_click`, `video_play`, `video_end`.

## Ограничения и требования
- 152-ФЗ: персональные данные граждан РФ — хранение на серверах в РФ; галочка согласия обязательна; `privacy.html` должна быть заполнена.
- Telegram и WhatsApp в РФ ограничиваются, поэтому заявка всегда дублируется на e-mail и в `storage/leads.log`.
- MAX: API `https://platform-api2.max.ru`, токен в заголовке `Authorization` (без Bearer), личный диалог адресуется по `user_id`. Домен использует сертификат Минцифры — может понадобиться `ca_file` в конфиге.
- Секреты только в `api/config.php` (в .gitignore).
- Доступность: видимый фокус, контраст ≥ 4.5:1, `prefers-reduced-motion`.
