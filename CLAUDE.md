# CLAUDE.md — контекст для Claude Code

## Что это
Статический лендинг (HTML/CSS/vanilla JS) + один PHP-эндпоинт для заявок. Без сборщиков и фреймворков — так задумано: владелец не технический специалист, хостинг обычный shared с PHP.

## Бизнес-контекст
- Продукт: очные курсы Excel в РТУ МИРЭА (Москва), группы до 10 человек, 3 модуля (16 ч, 16 ч, 36 ч), удостоверение гос. образца.
- Преподаватель: Светлана Владимировна Кондратова, к.э.н., 20+ лет в финансах.
- Аудитория: руководители среднего звена, владельцы бизнеса, специалисты 25–45 лет, работающие с данными.
- Цель страницы: заявка (имя + телефон). Оплаты на сайте нет — преподаватель перезванивает.
- Трафик: Яндекс Директ. Этап — проверка спроса 1–2 месяца.

## Архитектура
- `a/index.html`, `c/index.html`, `g/index.html` — **одинаковая разметка**, различаются только содержимым hero (A — фото в арке, C — фото занятия + карточка преподавателя, G — табличка «до/после»), логотипом, подписями разделов (в G — в виде формул `=ПРОГРАММА()`), классами секции «Программа» и подключаемой темой. Любое изменение контента/разметки вносить во ВСЕ оставшиеся варианты.
- Владелец выберет два варианта из трёх для A/B-теста; лишний удаляется вместе с темой и `choose.html` (см. README).
- Цвета/шрифты/радиусы — только через CSS-переменные в `theme-*.css`. В `base.css` не хардкодить цвета.
- `main.js`: не использовать `form.name`/`form.phone` (конфликт со свойствами HTMLFormElement) — только `form.elements['...']`.
- Форма шлёт JSON на `../api/lead.php`. Ответ: `{ok:true}` или `{ok:false,error}`.
- Кнопки с `data-cta` шлют цель `cta_click`; `data-module="…"` подставляет модуль в `<select name="module">` (значение должно ТОЧНО совпадать с `<option value>`); `data-payer="company"` выбирает радиокнопку.

## Цели Метрики (идентификаторы JS-событий)
`lead` (успешная отправка — главная цель для Директа), `lead_error`, `cta_click`, `program_open`, `phone_click`, `messenger_click`.

## Ограничения и требования
- 152-ФЗ: персональные данные граждан РФ — хранение на серверах в РФ; галочка согласия обязательна; `privacy.html` должна быть заполнена.
- Telegram и WhatsApp в РФ ограничиваются, поэтому заявка всегда дублируется на e-mail и в `storage/leads.log`.
- MAX: API `https://platform-api2.max.ru`, токен в заголовке `Authorization` (без Bearer), личный диалог адресуется по `user_id`. Домен использует сертификат Минцифры — может понадобиться `ca_file` в конфиге.
- Секреты только в `api/config.php` (в .gitignore).
- Доступность: видимый фокус, контраст ≥ 4.5:1, `prefers-reduced-motion`.
