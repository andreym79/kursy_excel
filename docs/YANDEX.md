# Яндекс Метрика и Директ

## Счётчик Метрики
1. metrika.yandex.ru → «Добавить счётчик», адрес сайта, включить Вебвизор.
2. Номер счётчика (8 цифр) вписать в обоих файлах `a/index.html` и `c/index.html`:
   `window.LANDING_CONFIG = { metrikaId: 12345678, ... }`
   Код счётчика уже встроен и включается автоматически, когда номер не равен 0.

## Цели (Метрика → Настройки → Цели → «JavaScript-событие»)
| Идентификатор | Когда срабатывает | Использование |
|---|---|---|
| `lead` | заявка успешно отправлена | **главная цель** для оптимизации в Директе |
| `cta_click` | нажата любая кнопка записи | промежуточная |
| `program_open` | раскрыта программа модуля | интерес к содержанию |
| `phone_click` | клик по телефону | микроконверсия |
| `messenger_click` | клик по ссылке мессенджера | микроконверсия |
| `lead_error` | ошибка отправки | контроль технических сбоев |

## Директ
В кампании указать номер счётчика и цель `lead` как ключевую.

**yclid** Директ добавляет к ссылке автоматически (при привязанном счётчике).

**UTM-шаблон** — добавить к ссылке каждого объявления:
```
?utm_source=yandex&utm_medium=cpc&utm_campaign={campaign_id}&utm_content={ad_id}&utm_term={keyword}
```
Для A/B-теста дизайна: одна группа объявлений ведёт на `https://ВАШ-ДОМЕН.ru/a/…`, другая — на `https://ВАШ-ДОМЕН.ru/c/…`. Вариант страницы приходит в заявке и виден в Метрике по URL.

Метки первого визита хранятся в браузере 30 дней: если человек вернулся позже напрямую, заявка всё равно привяжется к объявлению.
