# Запуск: хостинг, боты, почта

## 1. Хостинг
Любой российский хостинг с PHP 7.4+ и curl (Beget, Timeweb и т. п.). Сервер в РФ — требование 152-ФЗ.
Подключите домен и бесплатный SSL (Let's Encrypt) — без HTTPS форма и Метрика работают хуже, а Директ может отклонить объявления.

Загрузите все файлы проекта в корень сайта. Проверьте, что `https://ВАШ-ДОМЕН.ru/api/config.php` и `https://ВАШ-ДОМЕН.ru/storage/leads.log` **не открываются** (ошибка 403). Если хостинг на nginx без .htaccess — попросите поддержку закрыть эти пути.

## 2. Настройки заявок
```
cp api/config.example.php api/config.php
```
Заполните `allowed_origins` своим доменом. Включайте минимум два канала.

### Telegram (5 минут)
1. В Telegram найти @BotFather → `/newbot` → получить токен.
2. Ответственный пишет своему боту любое сообщение.
3. Открыть в браузере `https://api.telegram.org/bot<ТОКЕН>/getUpdates`, найти `"chat":{"id": ...}` — это `chat_id`.
4. В `config.php`: `enabled => true`, `bot_token`, `chat_id`.
Для группы: добавить бота в группу, написать в неё сообщение, `chat_id` будет отрицательным.

### MAX (1–3 дня из-за модерации)
1. Верифицировать ИП / организацию / самозанятость на платформе MAX для партнёров.
2. Создать бота, дождаться модерации (обычно до 48 часов), скопировать токен.
3. Ответственный пишет боту → узнать его `user_id` (через `GET /updates` или логи вебхука).
4. В `config.php`: `enabled => true`, `bot_token`, `user_id`. Если хостинг не доверяет сертификату Минцифры — скачать корневой сертификат с Госуслуг и указать путь в `ca_file`.

### E-mail
Включён по умолчанию. `from` должен быть адресом на вашем домене, иначе письма попадут в спам. Если письма не доходят — попросите хостинг включить отправку или настройте SMTP (задача для Claude Code: PHPMailer + SMTP Яндекс 360).

## 3. Проверка
Откройте `https://ВАШ-ДОМЕН.ru/a/?utm_source=test&utm_term=проверка`, отправьте заявку. В сообщении должны быть «Источник: test» и «Ключевая фраза: проверка». Повторите для `/c/`.
