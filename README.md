# Лендинг курса «От новичка до уверенного пользователя Excel»

Одностраничный сайт для набора офлайн-групп (РТУ МИРЭА, Москва) с приёмом заявок в мессенджер и на почту и подготовкой к рекламе в Яндекс Директе.

Три варианта дизайна. Сначала выбираете два, затем они идут в A/B-тест в Директе:

| Адрес | Вариант | Для кого сильнее |
|---|---|---|
| `/a/` | **A — «Академический премиум»**: тёмно-синий, слоновая кость, золото, заголовки с засечками | руководители, оплата через компанию, модуль 3 |
| `/c/` | **C — «Тёплый и живой»**: крем, терракота, шоколад, шалфей, мягкие формы | новички, специалисты, оплата из своего кармана |
| `/g/` | **G — «Табличный»**: глубокий зелёный, бумага, янтарные кнопки, подписи-формулы, табличка «до/после» в hero | узнаваемый «экселевский» образ, специалисты |

Корень `/` перенаправляет на `/a/`. Служебная страница `/choose.html` показывает все три варианта рядом.

## Как оставить два варианта
1. Открыть `/choose.html`, выбрать два варианта.
2. Удалить папку лишнего варианта (`a/`, `c/` или `g/`) и его `assets/css/theme-*.css`.
3. Удалить `choose.html`. Если удалён вариант A — поменять адрес в `index.html` (редирект) на оставшийся.
4. Обновить таблицу выше и `CLAUDE.md`.

## Структура

```
a/index.html            вариант A
c/index.html            вариант C
g/index.html            вариант G
choose.html             служебная страница выбора (удалить после выбора)
assets/css/base.css     общая раскладка и компоненты
assets/css/theme-a.css  цвета, шрифты и hero варианта A
assets/css/theme-c.css  цвета, шрифты и hero варианта C
assets/css/theme-g.css  цвета, шрифты и hero варианта G
assets/js/main.js       меню, подстановка модуля, UTM-метки, отправка формы, цели Метрики
assets/img/             изображения (сейчас только фото преподавателя)
api/lead.php            приём заявки → Telegram / MAX / e-mail + копия в файл
api/config.example.php  шаблон настроек (скопировать в api/config.php)
storage/                резервная копия заявок (закрыта от браузера, не в git)
privacy.html            шаблон политики обработки ПДн (обязательна по 152-ФЗ)
docs/SETUP.md           пошаговый запуск: хостинг, боты, почта
docs/YANDEX.md          Метрика, цели, UTM-шаблон для Директа
docs/CONTENT-TODO.md    что заполнить перед запуском
CLAUDE.md               контекст проекта для Claude Code
```

## Быстрый старт

1. Заполнить плейсхолдеры по `docs/CONTENT-TODO.md`.
2. Скопировать `api/config.example.php` → `api/config.php`, вписать токены и почту (`docs/SETUP.md`).
3. Создать счётчик Метрики и вписать номер в `window.LANDING_CONFIG.metrikaId` во всех `index.html` (`docs/YANDEX.md`).
4. Загрузить файлы на хостинг с PHP 7.4+ и HTTPS.
5. Отправить тестовую заявку и убедиться, что она пришла во все каналы.

Локально: `php -S localhost:8000` в корне проекта, затем открыть http://localhost:8000/a/.
