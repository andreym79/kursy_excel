# Лендинг курса «От новичка до уверенного пользователя Excel»

Одностраничный сайт для набора офлайн-групп (РТУ МИРЭА, Москва) с приёмом заявок в Mini CRM, мессенджер и на почту и подготовкой к рекламе в Яндекс Директе. Цены, даты, расписание и контакты меняются в CRM («Настройки → Тексты сайта»).

Два варианта дизайна для A/B-теста в Директе (третий, «G — Табличный», удалён 22.10.2026, он есть в истории git):

| Адрес | Вариант | Для кого сильнее |
|---|---|---|
| `/a/` | **A — «Академический премиум»**: тёмно-синий, слоновая кость, золото, заголовки с засечками | руководители, оплата через компанию, модуль 3 |
| `/c/` | **C — «Тёплый и живой»**: крем, терракота, шоколад, шалфей, мягкие формы | новички, специалисты, оплата из своего кармана |

Корень `/` перенаправляет на `/a/`.

## Структура

```
a/index.html            вариант A (разметка; тексты из CRM отмечены data-cms)
a/index.php             отдаёт a/index.html с текстами из CRM
c/index.html, index.php вариант C — так же
assets/css/base.css     общая раскладка, компоненты и правила доступности (фокус, контраст)
assets/css/theme-a.css  цвета, шрифты и hero варианта A
assets/css/theme-c.css  цвета, шрифты и hero варианта C
assets/js/main.js       меню, подстановка модуля, UTM-метки, отправка формы, цели Метрики
assets/fonts/           шрифты на самом сайте (woff2), без обращений к Google
assets/video/           видео-кружок «ВПР и клавиша F4»: mp4, обложка, субтитры .vtt
assets/img/             фото преподавателя и класса (WebP + JPG), значки сайта favicon-a/c.svg
api/lead.php            приём заявки → Mini CRM / Telegram / MAX / e-mail + копия в файл
api/cms.php             тексты из CRM: загрузка, кэш storage/cms-cache.json, подстановка в data-cms
api/cms-fields.php      список изменяемых полей для CRM (открывается как /cms-fields.json)
api/config.example.php  шаблон настроек (скопировать в api/config.php)
storage/                резервная копия заявок и кэш текстов из CRM (закрыта от браузера, не в git)
privacy.html            шаблон политики обработки ПДн (обязательна по 152-ФЗ)
.htaccess               index.php для страниц, /cms-fields.json, сжатие и кэш (Apache)
docs/SETUP.md           пошаговый запуск: хостинг, CRM, боты, почта
docs/YANDEX.md          Метрика, цели, UTM-шаблон для Директа
docs/CONTENT-TODO.md    что заполнить перед запуском
CLAUDE.md               контекст проекта для Claude Code
```

## Быстрый старт

1. Заполнить плейсхолдеры по `docs/CONTENT-TODO.md`.
2. Скопировать `api/config.example.php` → `api/config.php`, вписать токены и почту (`docs/SETUP.md`).
3. Создать счётчик Метрики и вписать номер в `window.LANDING_CONFIG.metrikaId` во всех `index.html` (`docs/YANDEX.md`).
4. Загрузить файлы на хостинг с PHP 7.4+ и HTTPS.
5. Отправить тестовую заявку и убедиться, что она пришла во все каналы.

Локально: `php -S localhost:8000` в корне проекта, затем открыть http://localhost:8000/a/.
